# Inventory Management System

## 📌 Overview
The **Inventory Management System** is a Java-based application that helps businesses efficiently track, manage, and update their inventory. It includes features for adding, updating, and removing products, viewing inventory levels, and generating reports.

## 🚀 Features
- 📦 **Product Management** – Add, update, and remove inventory items.
- 🔍 **Search Functionality** – Quickly search for products.
- 📊 **Stock Tracking** – Monitor inventory levels in real-time.
- 📜 **User Authentication** – Secure login system.
- 🖼 **Graphical User Interface (GUI)** – User-friendly interface built with Java Swing.
- 📁 **Data Persistence** – Uses file handling or a database to store inventory details.

## 🛠️ Technologies Used
- **Java** – Core programming language.
- **NetBeans** – IDE for development.
- **Swing** – For GUI development.
- **File I/O / Database** – For data storage.
- **Git & GitHub** – Version control.

## 📥 Installation
1. **Clone the repository**  
   ```bash
   git clone https://github.com/Naqashajmal/Inventory_Management_System.git
   ```
2. **Open in NetBeans**  
   - Navigate to **File** → **Open Project** → Select the cloned project.
3. **Run the project**  
   - Click the "Run" button or press **Shift + F6**.

- **Database Setup (if applicable)**  
  - Create a database and update connection details in the source code.
- **Edit Inventory Data**
